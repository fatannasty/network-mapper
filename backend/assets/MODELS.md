# Device Models - Icon Mapping (unique models)

Upload new icons to `backend/assets/icons/` named exactly as shown in the "icon"
column (or the model name itself, e.g. `mr53.png`, `c9300l-24p-4x.png`). The matcher
finds icons by model name, hyphenated prefixes, and brand prefixes, so pick whichever
name is easiest. For Meraki devices either `mr53.png` or `meraki-mr53.png` works;
for Cisco either `c9300x-24y.png` or `cisco-c9300x-24y.png`.
