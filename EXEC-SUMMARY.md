# Executive Summary — One-Page Opening Slide

**Amtrak Network Mapper** — a single platform to see, monitor, and report on the network.

---

1. **One source of truth for the network**
   Maps **3,900+ devices, 20,000+ interfaces, 42,000+ links across 350+ sites**
   from Catalyst, SNMP, Meraki, and VeloCloud SD-WAN — in one interactive view.

2. **Health & risk at a glance**
   A live scorecard tracks device uptime, **single points of failure**, flapping
   links, and coverage quality — with alerts that reach you before users notice.

3. **Built for every audience**
   A guided tour and plain-language glossary for newcomers, deep engineering
   tools for network teams, and an **executive dashboard** for leadership.

4. **Automation that keeps data fresh**
   Scheduled scans, utilization sampling, config backups, health snapshots, and
   alert checks run continuously — no manual upkeep.

5. **Answers, not just diagrams**
   One-click **executive reports (PDF/HTML with charts)** and clean CSV exports
   (interfaces, VLANs, ports, links) — scheduled and emailed automatically.

6. **Production-ready**
   **236 automated tests**, hardened security (RBAC, encrypted credentials, API
   tokens), smooth at scale, and a validated Docker deployment.
